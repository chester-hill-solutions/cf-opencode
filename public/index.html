Aboiteau brings the repository, model connection and conversation together. You decide where the work begins.

  1. 01

    Bring a repository or start fresh

    Start general work, or bind a repository and branch per conversation. Connect GitHub when the repository is private.

  2. 02

    Connect your model

    Use a provider API key or an available sign-in method. Choose from the connected provider’s live model catalogue.

  3. 03

    Start a conversation

    With the Slack adapter configured, mention Aboiteau in a thread or send a DM. HTTP and streaming events are available too.
